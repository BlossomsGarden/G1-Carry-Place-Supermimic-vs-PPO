# 🔬 实验结果、代价与失败复盘

**任务**：同一条 500 帧参考、同一 0.5 kg 箱体与 G1/MuJoCo 场景，两训练器从头运行，固定训练随机种子 0；评测从第 0 帧起步、策略确定性推理，打开物理域随机化、重置扰动和观测噪声。箱体没有被吸附到双手，结果来自物理状态与碰撞记录。[原始训练账本](metrics/summary_post_sm.json) · [四组账本](metrics/sm4096_fourway_summary.json) · [触地几何复核](metrics/sm4096_floor_guard_summary.json)。

## 三层判据：终点位置为主指标

1. **主指标：终点箱体到位**。在每条真实 MuJoCo 回放的**最后一帧**，取箱中心与参考轨迹目标箱中心的三维欧氏距离，≤ **0.12 m** 为 1，否则为 0；无箱体朝向、举升、接触、放手、速度、机器人是否站立或片段走完的附加门槛。纯稀疏的“箱子是否在目标附近”结果可包含拖行/意外碰撞造成的到位，**不能单独证明可靠搬运**。提前终止也按最后一帧计算，另记提前终止率。
2. **过程指标：间歇持物完成**。实际举升至少 0.15 m；高出起点 0.05 m 且不接地的连续时段 ≥10 帧、水平净搬运 ≥0.5 m；箱子最终 XY ≤0.12 m、高度 ≤0.06 m、姿态 ≤0.35 rad；末尾双手脱离、箱体落地并静止、机器人站立并走完参考轨迹；举升附近两只手均触碰过箱子，空中至少有单手接触的帧占比 ≥20%。**容许双手接触中断**。
3. **过程指标：严格连续双手成功**。必须先连续 ≥0.1 s 双手触箱，随后**不间断双手接触**、无地面支撑地搬运 ≥0.5 m；再满足到位、放开落地、稳定、站立及片段完成等门槛。“箱子到位”“间歇持物”“持续双手抓握”必须分别报告，不互相替代。[终点与间歇评分](../scripts/score_carry_object_outcome.py) · [严格物理评分](../src/mjlab_g1/tasks/smtrack/carryplace_eval.py)。

**重评方法**：不重新训练、不重新生成 GPU rollout；只用已有每条真实物理回放的终点 XY/高度误差计算三维距离，给每集加一个二值标签。覆盖 4 组 SuperMimic × 3 种子 × 64 集及 PPO × 2 种子 × 64 集，共 **896 条**；数据与旧过程指标出自同一批校正后的 per-episode 文件。新 [逐集重评结果和源 JSON SHA256](metrics/terminal_goal_3d_12cm_rescore.json) 可用 `python scripts/rescore_terminal_placement.py` 重新生成。PPO 原始 `ppo3999_heldout_*.json` 属于另一批回放，位置可能有厘米级差异，此处只使用与已发表过程指标同批的 `ppo3999_seed*_n64_geometry.json`，不跨批拼接单集数据。四组入选轮次先前用种子 0 的开发集**旧指标**选择；在三个验证种子上按新主指标排列，仅作描述，不能当成预注册盲测最优模型。

原 Warp 回放里，箱体中心超过 0.33 m 时仍曾被报“碰地”；当前网格顶点最大半径 0.29545 m、地面 z=0，因此这些接触**几何上不可能**。评分器只剔除这一类记录，低位拖地、目标误差、手箱接触和站立阈值都不放宽。旧评分文件保留；以下用**同一批实际回放**做几何修正后的结果。改箱型或地面高度后，必须重推 0.33 m 上界。

## 四组单卡 SuperMimic

每组 **1 张 24 GiB RTX 4090 × 4,096 个同时仿真环境**，训练种子均为 0，单条相同示范；世界模型每轮使用真实 replay，策略每轮选 4,096 个**想象起点**，分 16 个 microbatch（每块 256 起点）累积同一次梯度更新，想象时域 H=16 或 32。`box-ori-std` 是箱体**朝向跟踪奖励的误差尺度（弧度）**，不是策略动作噪声。四组都训练完整 1,000 轮、各产生 10,371,072 条真实物理转移（含 131,072 次初始预填充）；**按修正后的种子 0 开发集 16 条回放选择检查点**，再看其他三种子各 64 条随机化回放。

最佳配方 H32/1.2 在三个种子 **188/192** 到位，但其中 **20 条**虽然箱子在目标附近却不满足间歇持物完整流程：主要是箱体末段仍在动、未确认放下，或朝向误差超限。核查逐集记录，这 20 条都达到举升与净空中搬运门槛；896 条中没有到位但提前终止的样本。纯位置指标仍可能被拖行或意外碰撞投机，不能据此证明稳定抓握。

## PPO baseline：同任务，不同预算

正式 PPO-Sim 由 **4 卡 × 每卡 2,048 = 全局 8,192 环境**从头训练 4,000 轮，末轮文件 `model_3999.pt`；墙钟 9,272 s = **2 h 34 m 32 s**、**10.302 GPU·h**、**786,432,000 条真实转移**，最近 100 轮 **86,216 真实环境步/秒**。各训练卡整卡显存峰值：GPU 0 **6,288 MiB**，GPU 1/4/5 各 **4,922 MiB**。同一检查点、种子 2027 与 314159 各 64 条：

| 物理指标 | 2027 | 314159 | 合计 |
|---|---:|---:|---:|
| **终点箱体三维到位（主指标）** | **64/64** | **63/64** | **127/128 = 99.2%** |
| **间歇持物**（校正触地） | 64/64 | 63/64 | **127/128 = 99.2%** |
| **连续双手**（校正触地，与上表同口径） | 22/64 | 31/64 | **53/128 = 41.4%** |
| 严格成功（原始未校正评分） | 22/64 | 29/64 | 51/128 = 39.8% |

PPO 同批逐集几何评分：[2027](metrics/ppo3999_seed2027_n64_geometry.json) · [314159](metrics/ppo3999_seed314159_n64_geometry.json)；每条同时记录**原始严格判断**与**过滤不可能触地后的严格判断**，同批合计分别为 51/128 与 53/128。[历史原始评测 2027](metrics/ppo3999_heldout_seed2027_64.json) · [314159](metrics/ppo3999_heldout_seed314159_64.json) 是另一次回放，虽然合计也为 51/128，单集终点厘米级误差会波动，不能和上述几何批逐集拼接。PPO 的 2027 早已用于诊断；314159 未用于最佳检查点选择，但也不是外部盲测。视频 [严格成功一条](../assets/ppo3999_seed314159_episode59_physical.mp4)又来自**独立重录批次**，该批为 30/64，不能替换任何上表分母。

**同口径交集**：只看两方法都测过的种子 2027、314159，最优 SuperMimic H32/1.2 的**终点到位 124/128 = 96.9%**、间歇持物 110/128 = 85.9%、连续双手 0/128；PPO 依次为 **127/128 = 99.2%**、127/128 = 99.2%、53/128 = 41.4%。前者达到选中权重花约 **3.75 单卡 GPU·h / 1,037 万真实转移**，后者完整训练 **10.302 四卡 GPU·h / 7.864 亿转移**；约少 76 倍真实交互仅是预算比，**并非相同成功质量下的样本效率或算法成本结论**。全局环境数、训练卡数、架构、优化步骤均不同；想象计算不计入真实环境步，但已经计入墙钟和 GPU·h。要量化算法优势，还需多训练种子、相同 GPU·h/仿真步预算的学习曲线及不同过程指标的共同约束。

**经验**：缩短想象时域 H32→H16 把真实吞吐从约 776/778 提高至 1,266/1,278 步/秒，但四组最佳权重的物理完成率并不随速度单调变化；H16/1.2 在第 800 轮开发集较好，第 1,000 轮反而退化，必须保存检查点而不是只看最新 reward。校正几何假接触同时改变了四组优选及 PPO 的原始严格成功计数，说明评测器也要做几何和逐帧验证。**尚未解决**：持续双手接触、箱体相对滑动、更多箱重/箱型/参考轨迹/训练种子与真实机器人迁移；当前 87.5% 不表示拿起任意箱子都可靠，更不能声称复现论文的 1000× GPU-hours。
